**What I work with:** Snowflake, dbt, SQL, Python, GitHub Actions, and MCP for connecting AI agents to data.

**What's here**

It resolves "JPM", "J.P. Morgan" and "JPMorgan Chase & Co." to one entity, fails loudly on bad references, and builds an evidence pack an LLM can cite. Tested in CI.
